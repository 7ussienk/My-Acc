# حساباتي — الإصدار 8.0

تطبيق شخصي يجاوب على ثلاثة أسئلة: كم باقي في كل حساب، كم لي عند الناس، وكم دفعت على كل بند.
الواجهة صفحة ثابتة على GitHub Pages، والبيانات في قاعدة Postgres على Supabase.

## كيف يشتغل

- **دفتر حركات واحد** (`transactions`): كل حركة لها نوع ومبلغ وحساب. الأرصدة والمستحقات ومدفوعات البنود تُحسب منه، ما فيه أرقام مخزنة تتعارض.
- **محلي أولًا**: التطبيق يشتغل على نسخة محفوظة في الجوال (IndexedDB)، فيفتح ويسجّل بدون نت، ويزامن مع القاعدة في الخلفية.
- **المزامنة آمنة للتكرار**: كل صف له معرّف يولّده الجوال، والرفع upsert بالمعرّف. الحذف ناعم (`deleted_at`) حتى يوصل لكل الأجهزة.
- **الحماية**: دخول بإيميل وكلمة سر، وكل جدول عليه RLS (كل مستخدم يشوف صفوفه فقط). المفتاح في `config.js` هو المفتاح العام.

| النوع (`kind`) | المعنى | أثره على الحساب |
|---|---|---|
| `payment` | دفعة على بند | ينقص |
| `claim` / `repay` | دفعت عن غيري / استرجعت | ينقص / يزيد |
| `income` | دخل | يزيد |
| `expense` | مصروف عام (من مطابقة الرصيد) | ينقص |
| `transfer` | تحويل بين حسابين | ينقص من الأول ويزيد الثاني |
| `adjust` | رصيد افتتاحي أو تسوية | يزيد أو ينقص |

## الملفات

- `index.html` — الصفحة والتنسيق.
- `js/compute.js` — محرك الحساب (دوال نقية: دفتر ← أرصدة وتقارير).
- `js/store.js` — التخزين المحلي، تسجيل الدخول، والمزامنة مع Supabase.
- `js/app.js` — الواجهة.
- `js/legacy.js` — ترحيل مرة واحدة من النسخة القديمة (Google Sheets).
- `supabase/schema.sql` — الجداول والفهارس وقواعد الحماية.
- `config.js` — رابط المشروع والمفتاح العام.
- `sw.js`, `manifest.webmanifest`, الأيقونات — للتثبيت كتطبيق والعمل بدون نت.

## الإعداد (مرة واحدة)

1. في Supabase: أنشئ مشروعًا جديدًا (أو استخدم مشروعًا موجودًا).
2. SQL Editor ← الصق محتوى `supabase/schema.sql` كاملًا ← Run.
3. Authentication ← Users ← Add user: إيميلك وكلمة سر قوية (فعّل Auto Confirm).
4. Authentication ← Sign In / Providers: عطّل «Allow new users to sign up» حتى ما يسجّل أحد غيرك.
5. Project Settings ← API: انسخ Project URL والمفتاح العام (anon أو publishable) إلى `config.js`.
6. ارفع كل الملفات على GitHub Pages (مع مجلد `js`). لا ترفع `.claude` ولا `Code.gs`.
7. افتح التطبيق وسجّل الدخول، ثم: الإعدادات ← ترحيل البيانات من Google Sheets ← الصق رابط `/exec` القديم والرقم السري القديم ← ابدأ الترحيل.

## ملاحظات على الترحيل

- ينقل الدفعات، المصاريف، المداخيل، التحويلات، والمستحقات بتواريخها الأصلية، مع البنود وميزانياتها.
- يضيف لكل حساب حركة «رصيد افتتاحي» بحيث يطابق رصيده رقم الشيت بالضبط.
- السجلات القديمة اللي بدون حساب تروح لحساب مؤرشف اسمه «غير محدد (قديم)» ورصيده صفر.
- بيانات الريال اليمني وورقة الصرف ما تنتقل (كانت مخفية من الإصدار 6)، وأثرها محسوب ضمن الرصيد الافتتاحي.
- التحويلات في شهر ما فيه أي حركة ثانية ما تظهر في تقارير النسخة القديمة فما تنتقل؛ الأرصدة تبقى صحيحة.
- بعد التأكد من الأرقام تقدر تترك الشيت وApps Script كأرشيف.

## للتطوير

المشروع الجديد في Supabase يتوقف مؤقتًا في الخطة المجانية لو ما انفتح أسبوعًا؛ يرجع بضغطة من لوحة التحكم، والتطبيق يكمل من النسخة المحلية ويزامن بعدها.
